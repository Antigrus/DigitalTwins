# 设计说明

## 初始化顺序
1. 读取节点配置和轨迹。
2. 读取所有阵面几何参数、频率和单阵元功率。
3. 调用 `BeamTable_InitAllNodes()` 遍历全部节点阵面。
4. 每个阵面调用 `BeamTable_GetOrCreate()`：顺序查找全局缓存，命中复用索引，未命中计算 181x181 表并写入缓存。
5. 动态仿真阶段根据节点 `tr_state` 决定链路方向。

## 坐标约定
节点局部 +X 沿节点速度方向。阵面局部 +X 为阵面法向，+Y 为横向阵列轴，+Z 为纵向阵列轴。阵面全局旋转矩阵为 `R_node * R_mount`。全局方向使用旋转矩阵转置变换到阵面局部坐标。

## 缓存键
只包括横向阵元数、纵向阵元数、横向间距、纵向间距、频率。阵面安装位置、安装姿态和单阵元发射功率不改变局部阵列因子表，因此不参与缓存键。


## 发射阵面选择、波束扫描与结果集合

- 节点 `tx_array_id` 保存指定发射阵面 ID，`-1` 表示自动选择；它引用 `ArrayMount.id`，不引用数组下标。
- 节点 `beam_direction` 是阵面局部扫描偏移，单位为度。最终方向矩阵为 `R_node * R_mount * R_scan`，扫描不会改变阵面的安装姿态。
- `g_tri_nodes_cal_result` 按 `(txid,rxid,txaid,rxaid)` 保存每条链路最新 `ChannelResult`；同键覆盖，不同键追加。访问同步由调用方负责。
